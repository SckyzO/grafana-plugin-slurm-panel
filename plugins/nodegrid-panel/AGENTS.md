## Project knowledge

This is one package of the **slurm-views** workspace, not a standalone plugin
repository. Read [`../../CLAUDE.md`](../../CLAUDE.md) before making any
change: it is the authority here, and it contradicts the scaffolded
instructions under `.config/AGENTS/` on the points that matter most.

In short, and this is the part the scaffold gets wrong for this repository:

- **Everything runs through `make`, from the repository root.** Never run
  `pnpm`, `node`, `npx`, `tsc`, `jest`, `playwright` or `docker` directly.
  The toolchain lives in a container and `node_modules` lives in a Docker
  volume; a host run installs nothing the container can see.
- **Do not weaken the supply-chain settings** in `pnpm-workspace.yaml` to make
  an install succeed. A blocked install is the control working.
- **Ports 3000 and 9090 belong to the maintainer's own stack.** This project
  publishes on 3001 / 9091.

`.config/AGENTS/instructions.md` is scaffolded by `@grafana/create-plugin`
and regenerated by its updates, so it is not edited. Its guidance on fetching
Grafana documentation from grafana.com, and on not touching `.config`, is
good and still applies. Its guidance on running builds and tests does not:
it will tell you to detect a package manager and invoke it here.
